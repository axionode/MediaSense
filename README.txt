MediaSense 1.0
Быстрый просмотр, поворот, обрезка и конвертация фото и видео. Windows 10 и 11, 64 бита.

ЧТО В ПАПКЕ
  MediaSense.exe      сама программа (около 0,5 МБ, работает и без установки)
  tools\ffmpeg.exe    конвертер видео и запасной декодер редких форматов
  Install.cmd         установка для текущего пользователя
  Uninstall.cmd       удаление
  SelfTest.cmd        самопроверка на файлах из test_media, пишет лог и снимки экрана
  AGENT_SETUP.md      инструкция для ИИ-агента: что доставить в систему и как проверить
  src, build.cmd      исходный код и сборка
  test_media          тестовые файлы для самопроверки, можно удалить

ЗАПУСК БЕЗ УСТАНОВКИ
  Двойной клик по MediaSense.exe, затем перетащить в окно файл или папку.
  Или перетащить файл прямо на MediaSense.exe.

УСТАНОВКА
  1. Двойной клик по Install.cmd. Права администратора не нужны, интернет не нужен.
  2. Программа копируется в %LOCALAPPDATA%\Programs\MediaSense, ярлыки появляются на рабочем столе и в меню Пуск.
  3. Чтобы файлы открывались двойным кликом: правый клик по фото или видео, "Открыть с помощью",
     "Выбрать другое приложение", MediaSense, галочка "Всегда". Windows не даёт программам назначать себя по умолчанию,
     поэтому этот шаг делается руками один раз для каждого типа файлов.
  4. В меню правой кнопки по фото, видео и папкам появится пункт "Открыть в MediaSense", сразу в верхнем блоке.
     В Windows 11 он находится в "Показать дополнительные параметры".
  Удаление: Uninstall.cmd или "Приложения и возможности". Сохранённые повороты остаются в %LOCALAPPDATA%\MediaSense.

УПРАВЛЕНИЕ
  Интерфейс появляется только при движении мыши и сам исчезает через пару секунд. Клавиши его не вызывают.
  У окна нет системной рамки: кнопки свернуть, развернуть и закрыть появляются справа вверху вместе с интерфейсом,
  окно перетаскивается за верхний край, размер меняется за края.
  Программа работает в одном окне: файл, открытый из проводника, попадает в уже запущенный MediaSense.

  Общее
  Стрелки влево и вправо     предыдущий и следующий файл
  L и R (или [ и ])          повернуть влево и вправо, поворот записывается в файл
  F                          плёнка: лента соседних файлов внизу, повторное нажатие скрывает
  C                          обрезка: рамка, пропорции, затем "Сохранить"
  E или Ctrl+S               конвертировать и сохранить
  G                          галерея папки
  F11, Enter, двойной клик   во весь экран
  Колесо мыши, + и -         масштаб, 0 вписать, 1 реальный размер; колесо над плёнкой листает файлы
  Ctrl+C                     скопировать файл в буфер (вставляется в проводник, мессенджер, письмо)
  Потянуть картинку мышью    перетащить файл в другую программу или папку
  Del                        удалить в корзину
  I или F1                   окно "Компоненты": какие кодеки стоят в системе
  Esc                        закрыть панель, снять выделение, выйти из полного экрана, закрыть программу
  Правая кнопка мыши         меню

  Видео
  Пробел                     пауза
  Ctrl + влево и вправо      перемотка на 30 секунд
  J и K                      перемотка на 5 секунд
  , и .                      шаг назад и вперёд примерно на кадр
  S                          скорость: 1x, 1.25x, 1.5x, 2x, 0.5x по кругу; Shift+S вернуть 1x
  O                          повтор ролика
  P                          сохранить текущий кадр как фото JPEG
  A и D                      начало и конец фрагмента для экспорта, X сбросить
  H                          улучшение видео (кнопка HD+), по умолчанию включено
  Вверх и вниз, M            громкость и звук

  Галерея
  Клик                       открыть файл
  Ctrl+клик, Shift+клик      выбрать несколько файлов; кнопка "Выбрать" включает выбор обычным кликом
  Ctrl+A                     выбрать всё
  S                          порядок: по имени или по дате (новые сверху)
  T                          показывать всё, только фото или только видео
  Панель внизу               повернуть, конвертировать или удалить выбранные файлы
  Потянуть миниатюру         перетащить файл или все выбранные файлы в другую программу

СОРТИРОВКА ПО ПАПКАМ
  Правая кнопка мыши по фото или видео, "Отправить в папку": в списке все папки, лежащие внутри текущей.
  Выбрали папку, и файл переезжает в неё, на экране сразу следующий.
  "Новая папка": вводите название прямо в программе, папка создаётся внутри текущей, файл переносится в неё.
  M                          отправить в ту же папку, что и в прошлый раз (для видео Ctrl+M, потому что M это звук)
  Ctrl+Z                     вернуть последнее перемещение
  В галерее то же меню работает на все выбранные файлы.
  Файл с таким же именем в папке назначения не затирается, к имени добавляется номер.

ПОВОРОТ
  Поворот применяется мгновенно и записывается в сам файл, поэтому файл остаётся повёрнутым в любой программе.
  Запись происходит, когда вы переходите к другому файлу, открываете галерею или закрываете программу.
  Видео MP4, MOV, M4V, 3GP: меняется только метка поворота, без перекодирования и без потери качества.
    Большой файл переписывается со скоростью диска, программа при закрытии дожидается конца записи в фоне.
  Фото JPEG: меняется метка ориентации EXIF, пиксели не трогаются.
  Остальные форматы (PNG, HEIC, MKV, AVI и другие): поворот запоминается только внутри MediaSense,
    в файле %LOCALAPPDATA%\MediaSense\rotations.txt. Чтобы получить повёрнутый файл, используйте экспорт (E).
  Для записи поворота в видео нужен tools\ffmpeg.exe.

КОНВЕРТАЦИЯ
  Фото: JPEG, PNG, TIFF средствами Windows, WebP через ffmpeg. Поворот и кроп учитываются.
  Видео: MP4 720p для телефона, MP4 под размер, MP4 1080p, MP4 в исходном размере, HEVC, без перекодирования, GIF, MP3.
  MP4 под размер: выберите 10, 25, 50 или 100 МБ, качество и разрешение подбираются под длительность. Точность около 10%.
  Фрагмент: клавишами A и D (или кнопками в панели экспорта) отметьте начало и конец, сохранится только этот кусок.
    В режиме "Без перекодирования" начало встаёт на ближайший опорный кадр, поэтому кусок может начаться чуть раньше.
  Несколько файлов сразу: выберите их в галерее и нажмите "Конвертировать".
  Если есть видеокарта NVIDIA, Intel или AMD, используется её аппаратный кодировщик, иначе x264.
  Папка назначения выбирается в панели экспорта и запоминается. По умолчанию файл кладётся рядом с исходным.

ФОРМАТЫ
  Фото через Windows: JPG, PNG, BMP, GIF (с анимацией), TIFF, ICO, DDS, JXR.
  Через расширения Windows: HEIC, WebP, AVIF, RAW с камер. Через ffmpeg: TGA, PSD, EXR, HDR, JPEG 2000 и другие.
  Видео: то, что умеет Media Foundation в вашей системе: MP4, MOV, MKV, AVI, WMV, 3GP, а с расширениями HEVC, AV1, VP9, MPEG-2.
  Что именно установлено, показывает окно "Компоненты" (клавиша I). Там же кнопка, которая копирует готовую
  инструкцию для ИИ-агента с командами установки недостающего.
  Видео, которое Windows не играет (например FLV), можно сконвертировать в MP4 клавишей E.

СЕТЬ
  Программа не выходит в интернет и ничего не обновляет. В коде нет сетевых вызовов.
  Интернет нужен только вам самим, если захотите доустановить кодеки из Microsoft Store.

СБОРКА ИЗ ИСХОДНИКОВ
  build.cmd. Нужен Python 3, компилятор ставится командой pip install ziglang.
  Код: C++17, Win32, Direct2D, DirectWrite, WIC, Media Foundation. Сторонних библиотек нет.

FFMPEG
  tools\ffmpeg.exe это сборка FFmpeg 8.1 (GPL) с github.com/BtbN/FFmpeg-Builds, лицензия лежит рядом.
  Без него работает просмотр и конвертация фото, но не конвертация видео.
